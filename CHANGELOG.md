# Changelog

## 0.2.0

- Redistributable `custom_components` layout, MIT license, HACS metadata, examples, CI, and release builder.
- Guided Choice, Noul, and Score question forms; advanced named question maps and a selectable primary answer.
- Configurable endpoints/models with typed-JSON and OpenAI-compatible chat backends.
- Saved URL/API key and automatic reuse of the most recently configured connection when building another sensor.
- Editable input entities, startup/change evaluation, debounce, manual-only mode, periodic refresh, and timeout.
- Numeric Noul and Score states, validated typed answers, metadata preservation, and redacted diagnostics.
- Serialized requests, bounded responses, debounced follow-up requests, and reliable unload cleanup.
- Compatibility with legacy Jev/Laya config entries and existing sensor unique IDs.
